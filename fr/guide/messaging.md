# Messagerie intégrée

La messagerie intégrée centralise les échanges **directement dans chaque dossier client**. Deux types de communication sont disponibles :

| Type | Qui échange | Visible par le client |
|------|-------------|-----------------------|
| **Messagerie interne** | Vous et vos collaborateurs | Non |
| **Messagerie client** | Vous et le client | Oui |

Le compteur « Messages non lus » de l'écran d'accueil vous aide à repérer les nouvelles questions de vos clients.

## Messagerie interne

Échangez avec vos collaborateurs au sein du dossier, sans que le client voie les messages.

1. **Ouvrir le dossier :** descendez jusqu'à la rubrique « Historique ».
2. **Écrire un commentaire :** saisissez votre texte dans « Laisser un commentaire interne... », puis cliquez sur « Publier ».
3. **Mentionner un collaborateur :** tapez « @ » (ou cliquez sur le bouton « @ ») pour choisir un collaborateur. Il reçoit alors une notification.

![Commentaire interne avec mention dans l'historique du dossier](/screenshots/messaging/internal-comment.png)

::: info Confidentialité
Seuls vous et les autres collaborateurs pouvez voir ces commentaires.
:::

## Messagerie client

Pour démarrer une nouvelle discussion avec le client, cliquez sur « Messages » dans la colonne de droite de la fiche client, rubrique « Informations clients ».

![Bouton Messages dans la fiche client](/screenshots/messaging/messages-button.png)

## Côté client : poser une question

Le client dispose de deux façons de vous écrire. Ses messages arrivent dans le dossier concerné.

### Message sur un module

Pour poser une question sur un module précis, le client clique sur la bulle de message située à côté du module concerné.

![Bulle de message à côté d'un module, côté client](/screenshots/messaging/client-module-bubble.png)

**Côté administrateur :** le message apparaît dans l'historique du dossier, avec le nom du module concerné. Cliquez dessus pour ouvrir la conversation et répondre directement au client. Les messages non lus sont signalés par « Non lu ».

![Message d'un client dans l'historique du dossier](/screenshots/messaging/admin-module-message.png)

![Conversation ouverte avec le module concerné](/screenshots/messaging/admin-conversation.png)

### Message global

Le client peut poser une question générale en cliquant sur le bouton « Une question ? », en bas à droite de son écran. Il retrouve votre réponse dans cette même messagerie.

![Bouton Une question ? côté client](/screenshots/messaging/client-global-question.png)

**Côté administrateur :** le message apparaît dans le dossier client. Cliquez dessus pour ouvrir la conversation et répondre au client.
