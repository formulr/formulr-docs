# Yousign

[Formulr Trust](./formulr-trust) est la solution de signature utilisée par défaut. **Yousign** reste disponible **sur demande uniquement**, par exemple si vous devez conserver ce prestataire pour des raisons internes.

## Activer Yousign

Faites la demande via votre accès **Support** en précisant les modules de signature concernés. Le choix se fait module par module : une même campagne peut donc garder Formulr Trust sur un module et Yousign sur un autre.

## Ce qui change

La configuration du module, les [zones de signature](./electronic-signature#zones-de-signature-dans-un-template-pdf) et le suivi dans la réponse sont **identiques** : tout est décrit dans [Signature électronique](./electronic-signature).

Seul le prestataire change :

- la signature dans le formulaire s'affiche dans la fenêtre Yousign ;
- les emails d'invitation (signataires multiples ou externes) sont envoyés par Yousign.

## Bon à savoir

- Passer un module de Yousign à Formulr Trust, ou l'inverse, ne modifie pas les signatures déjà lancées : elles se terminent avec leur prestataire d'origine.
- Aucun compte Yousign n'est à créer de votre côté.
