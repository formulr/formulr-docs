# Formulr Trust

**Formulr Trust** est la solution de signature électronique de Formulr. C'est la solution utilisée **par défaut** pour tout nouveau module [Signature électronique](./electronic-signature).

## Pourquoi Formulr Trust

- **Rien à configurer** : aucun compte tiers à créer, votre espace est activé automatiquement.
- **Signature intégrée au formulaire** : le répondant signe sans quitter la page, sans email ni lien externe.
- **Signature électronique simple conforme eIDAS**, au format **PAdES** : la signature est scellée dans le PDF et horodatée, vérifiable avec un lecteur PDF standard.
- **Document signé rattaché automatiquement** à la réponse, dès la signature terminée.

## L'expérience du signataire

1. **Consultation** : le répondant prévisualise le document.
2. **Signature** : il clique sur **Lancer la signature** et signe.
3. Le message **Document signé** confirme la signature. Il peut **Continuer** son formulaire ou **Télécharger** le document.

Avec plusieurs signataires ou un signataire externe, chacun reçoit un email d'invitation à signer.

## Utiliser Formulr Trust

Il n'y a rien à faire : tout nouveau module Signature électronique utilise Formulr Trust. La mise en place du module est décrite dans [Signature électronique](./electronic-signature).

::: info Modules existants
Un module de signature déjà configuré avant l'arrivée de Formulr Trust garde sa solution actuelle. Pour le passer sur Formulr Trust, faites la demande via votre accès **Support**. Les signatures déjà lancées ne sont pas modifiées.
:::
