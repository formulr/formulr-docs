# Yousign

[Formulr Trust](./formulr-trust) is the signature solution used by default. **Yousign** remains available **on request only**, for example if you need to keep this provider for internal reasons.

## Enable Yousign

Request it through your **Support** access, specifying the signature modules concerned. The choice is made module by module: the same campaign can keep Formulr Trust on one module and Yousign on another.

## What changes

The module setup, the [signature areas](./electronic-signature#signature-areas-in-a-pdf-template) and the tracking in the response are **the same**: everything is described in [Electronic signature](./electronic-signature).

Only the provider changes:

- signing in the form is shown in the Yousign window;
- invitation emails (several or external signers) are sent by Yousign.

## Good to know

- Switching a module from Yousign to Formulr Trust, or the other way round, does not affect signatures already started: they finish with their original provider.
- You do not need to create a Yousign account.
