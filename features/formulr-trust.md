# Formulr Trust

**Formulr Trust** is Formulr's electronic signature solution. It is the solution used **by default** for every new [Electronic signature](./electronic-signature) module.

## Why Formulr Trust

- **Nothing to set up**: no third-party account to create, your space is activated automatically.
- **Signing inside the form**: the respondent signs without leaving the page, with no email or external link.
- **eIDAS-compliant simple electronic signature**, in **PAdES** format: the signature is sealed in the PDF and timestamped, and can be checked with any standard PDF reader.
- **Signed document attached automatically** to the response as soon as signing is complete.

## The signer's experience

1. **Review**: the respondent previews the document.
2. **Sign**: they click **Launch signature** and sign.
3. The **Document signed** message confirms it. They can **Continue** their form or **Download** the document.

With several signers or an external signer, each one receives an email invitation to sign.

## Using Formulr Trust

There is nothing to do: every new Electronic signature module uses Formulr Trust. Setting up the module is described in [Electronic signature](./electronic-signature).

::: info Existing modules
A signature module configured before Formulr Trust was available keeps its current solution. To switch it to Formulr Trust, request it through your **Support** access. Signatures already started are not affected.
:::
